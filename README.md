# Ncourage Plugins

Photoshop plugins by [Ncourage](https://mncourage.com/work).

## Shadow Studio

Download: **https://is.gd/shadowstudio**

Double-click the file to install with Creative Cloud, then restart Photoshop and open **Plugins → Shadow Studio**.
Updates appear inside the panel automatically.

## Ncourage Toolkit (free)

Download: **https://is.gd/ncouragetoolkit**

Double-click the file to install with Creative Cloud, then restart Photoshop and open **Plugins → Ncourage Toolkit**.
Works in Photoshop 2024 and newer, on Mac and Windows. Updates appear inside the panel automatically.
